# Security Policy

## Supported versions

Security fixes are applied to the current default branch. Older deployments may not receive fixes.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner privately through their GitHub profile and include reproduction steps, impact, and any suggested mitigation.

Reports are reviewed as time permits. Do not include real personal data or credentials in a report.

## Response and disclosure

The maintainer will acknowledge a report, investigate it, and coordinate a fix and disclosure timeline with the reporter. Rotate any credentials that may have been exposed and revoke affected tokens immediately.

## Scope notes

The portfolio has no application-owned API, authentication, or database. The contact form uses browser-visible EmailJS configuration; those identifiers are not secrets. Contact-form abuse should also be reported to the maintainer and EmailJS.
